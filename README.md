# RX300 車床方案

Lexus RX300（2018，第四代）後座放倒後的車床規劃，比較 5 種做法：

- A 收納箱＋EVA 巧拼階梯
- B 夾板格子梁（9mm 合板十字插接）
- C EVA 格子梁（高密度 EVA 板十字插接）
- D 搬運籃＋夾板三角梁（預設、預算內）
- E 鋁擠架（參考，超出預算）

床面一律用塑鋁板，摺成 3～4 片收納。

`rx300-bed.html` 包含每個方案的參數化 3D 模型、側視圖、裁切清單與排版圖、購買清單、第一次製作步驟，以及每次安裝與拆收的清單。用瀏覽器直接打開即可（3D 需要連網載入 three.js）。

預設尺寸和單價大多是估計值，下單前請實測後填入頁面左側欄位。
